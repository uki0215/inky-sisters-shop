# 🛍️ "Inky Sisters" Бичиг Хэрэгийн E-Commerce Веб Сайт

Гүн ногоон өнгө төрхтэй, бүртгэлгүй шууд худалдан авалт хийх, Банкны QR кодоор төлбөр баталгаажуулах, бар кодын бүртгэл болон Юанийн өртөг ханш бодож зарах үнийг админ тохируулдаг иж бүрэн веб систем.

---

## 🌟 Гол боломжууд (Features)

### 🛒 1. Хэрэглэгчийн хэсэг (Home Page & Storefront)
- **Бүртгэлгүй Захиалга (Guest Checkout)**: Овог нэр, утас, хаяг оруулж шууд захиална.
- **Банкны QR Төлбөр**: 2-3 Банкны (Хаан Банк, Голомт, ХХБ) дансны дугаар, нэр, захиалгын утга болон QR код харагдана.
- **Дууссан Бараа (Out of Stock Badge)**: Үлдэгдэл `0` болоход Home page дээр автомат "Дууссан" харагдана. Админ дахин нэмэхэд автомат тайлагдана.
- **Хямдрал болон Промошн Поп-ап (Promo Modal)**: Сайтад орох/Refresh хийхэд хямдралын баннер нэг удаа поп-ап байдлаар гарна.
- **Динамик Цэс/Ангилал (Categories Menu)**: Админаас үүсгэсэн ангилууд цэс болон автоматаар гарч ирнэ.

### ⚙️ 2. Админ Удирдлагын Хэсэг (`/admin`)
- **Бар кодын систем (Barcode & Scanner Support)**: Физик бар код уншигчаар (USB Barcode Scanner) уншуулж хайх/бүртгэх. Бар кодгүй бол "Шинэ Код Үүсгэх" товчлууртай.
- **Юанийн Өртөг & Ханшийн Тооцоолуур**: Авсан үеийн Юанийн ханшаар (¥) нэг ширхэгийн өртгийг төгрөгөөр (₮) олох.
- **Админы Зарах Үнэ**: Зарах үнийг админ өөрөө оруулж/өөрчилж тохируулна.
- **Захиалга Баталгаажуулах**: Дансанд мөнгө ормогц "Төлбөр Баталгаажуулах" товч дарж хэрэглэгчийн төлөвийг шинэчлэх.
- **Санхүүгийн Тайлан**: Нийт борлуулалт, Орлого, Зарлага (Өртөг), Цэвэр ашиг, Үлдэгдэл барааны өртөг харах.
- **Банкны QR Удирдлага**: 2-3 Банкны мэдээлэл болон QR зургийг засах/нэмэх.

## 🚀 Компьютер дээр ажиллуулах (Local Setup)

```bash
# 1. Төслийн хавтас руу орох
cd shop

# 2. Сангуудыг суулгах
npm install

# 3. Өгөгдлийн баазыг бэлтгэх (SQLite)
npx prisma db push
npx prisma db seed

# 4. Веб сайтыг ажиллуулах
npm run dev
```

Браузер дээр **http://localhost:3000** руу орж Home Page-ийг харах ба **http://localhost:3000/admin** руу орж Админ хэсгийг ажиллуулна.

## 🌐 Vercel дээр Deploy хийх заавар

1. [Vercel.com](https://vercel.com) рүү нэвтэрч ороод **Add New Project** товчийг дарна.
2. GitHub дээрх `inky-sisters-shop` репозиторийг сонгож **Import** хийнэ.
3. Framework Preset: **Next.js**
4. Build Command: `npm run build`
5. **Deploy** товчийг дарснаар таны сайт хэдэн секундэд онлайнаар ажиллаж эхэлнэ!

> **Тэмдэглэл**: Vercel дээр Vercel Postgres эсвэл Neon / Supabase хэрэглэх бол `DATABASE_URL` орчны хувьсагчийг (Environment Variable) тохируулаарай.
